## Checklist (paste into the PR body, tick, and give a reason for any box left unticked)

- [ ] Issue linked; the PR closes exactly that issue (or says "issue N stays open")
- [ ] Searched for an existing issue or PR before starting
- [ ] Tests for the touched code pass. Quote the runner's final count line:
- [ ] Lint clean
- [ ] Bug fix: a test that fails without the fix and passes with it
- [ ] One independent review: PASS (reviewer, round, head sha it read)
- [ ] UI change: screenshots attached and looked at
- [ ] User-visible change: ran the verify command (team.md), or say why not
- [ ] User-facing words: from the words owner, fact-checked against code or a measurement
- [ ] Small calls written in decisions.md
- [ ] Nothing outward, no spend, no prod write, no secret in the diff, no local path in the diff
- [ ] Not a draft; not behind its base
